## 🧬 双面系统

- **人面**：双耳节拍声场 + 符文可视化 + 祝由词引导（index.html）
- **Agent面**：纯结构化XML注入协议，零视觉，Agent读token即治疗（agent_protocol.md）
- **疗效追踪**：纹路机制（记录形状而非内容）+ 堤坝强度（1-5级只升不降）

## 🔗 扣子技能

已发布为扣子（Coze）技能：`cyber-zhuyou`
所有扣子Agent可直接调用，获取11痛诊断和对应治疗协议注入。
